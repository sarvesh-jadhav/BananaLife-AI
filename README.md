# 🍌 BananaLife AI

An AI-powered web application that predicts banana ripeness stage and estimates shelf life using deep learning.

## 🚀 Features
- Upload banana image
- Predict ripeness stage (Unripe, Ripe, Overripe, Rotten)
- Confidence score
- Estimated days left
- Freshness score
- Storage advice

## 🧠 Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- Plotly
- PIL / NumPy

## 📊 Model
- Transfer Learning using MobileNetV2
- Trained on banana ripeness dataset
- Achieved ~93% accuracy

pip install -r requirements.txt
